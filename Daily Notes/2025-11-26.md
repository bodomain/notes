D### Run the KIMI K2 Stuff locally: 

I'll guide you through running the FocusTimer application locally. The process depends on whether you want to run the full-stack version (with Django backend) or just the static frontend version.

## Option 1: Running the Static Version (Easiest)

This is the quickest way to get started and see the application in action:

### Method 1: Using Python's Built-in Server
1. **Navigate to the project directory**:
   ```bash
   cd /path/to/focustimer
   ```

2. **Start a local server**:
   ```bash
   python -m http.server 8000
   ```

3. **Open your browser** and go to:
   ```
   http://localhost:8000
   ```

### Method 2: Using Node.js Serve
1. **Install serve globally**:
   ```bash
   npm install -g serve
   ```

2. **Navigate to the project directory** and run:
   ```bash
   serve .
   ```

3. **Open your browser** at the provided local URL.

## Option 2: Running the Full-Stack Version (Advanced)

If you want the complete experience with user authentication and data persistence:

### Backend Setup (Django)
1. **Navigate to the backend directory**:
   ```bash
   cd backend
   ```

2. **Create a virtual environment**:
   ```bash
   python -m venv venv
   
   # On Windows:
   venv\\Scripts\\activate
   
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Set up the database**:
   ```bash
   # For development, you can use SQLite (default)
   python manage.py migrate
   
   # Or for PostgreSQL, first install PostgreSQL and create a database
   # Then update the DATABASES setting in settings.py
   ```

5. **Create a superuser** (optional):
   ```bash
   python manage.py createsuperuser
   ```

6. **Run the development server**:
   ```bash
   python manage.py runserver
   ```

### Frontend Setup (React)
1. **Navigate to the frontend directory**:
   ```bash
   cd frontend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```

4. **The React app will open** at `http://localhost:3000`

## Configuration

### Environment Variables
Create a `.env` file in the backend directory:

```env
SECRET_KEY=your-secret-key-here
DEBUG=True
DB_NAME=focustimer
DB_USER=postgres
DB_PASSWORD=your-password
DB_HOST=localhost
DB_PORT=5432
```

### Database Setup
For PostgreSQL (optional):
1. Install PostgreSQL
2. Create a database: `createdb focustimer`
3. Update the database settings in `backend/timerapp/settings.py`

## Troubleshooting

### Common Issues
1. **Port already in use**:
   - Try a different port: `python -m http.server 8080`

2. **CORS errors** (full-stack):
   - Ensure the React app proxy is set correctly in `package.json`

3. **Database connection errors**:
   - Check PostgreSQL is running
   - Verify database credentials

4. **Static files not loading**:
   - Make sure you're running from the correct directory
   - Check file permissions

### Development Tips
- The static version uses localStorage for data persistence
- All timer data is saved locally in your browser
- Settings are remembered between sessions
- You can export/import data using browser dev tools
