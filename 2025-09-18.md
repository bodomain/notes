#### Quick Start for Loading Data Programmatically (Python Example)
If you're using Python (e.g., with pandas), you can fetch from FRED or ECB APIs. Here's a sample code snippet to load US and Germany data from FRED (adapt for others):

```python
import pandas as pd
from fredapi import Fred  # Install via: pip install fredapi (requires free API key from fred.stlouisfed.org)

# Get API key from FRED and set it
fred = Fred(api_key='your_api_key_here')

# Load US 10Y daily yields (last 10 years)
us_10y = fred.get_series('DGS10', start_date='2015-09-18', end_date='2025-09-18')
us_10y = us_10y.to_frame(name='US_10Y_Yield')

# Load Germany 10Y monthly yields (last 10 years; for daily, use ECB)
de_10y = fred.get_series('IRLTLT01DEM156N', start_date='2015-09-01', end_date='2025-09-01')
de_10y = de_10y.to_frame(name='DE_10Y_Yield')

# Combine and save to CSV
historical_data = pd.concat([us_10y, de_10y], axis=1).dropna()
historical_data.to_csv('10y_bond_yields.csv')
print(historical_data.tail())  # Preview last 5 rows
```

For ECB data (e.g., France/Germany daily), use the `ecb` library or direct CSV downloads from their portal. If you need data for UK/France via API, Trading Economics offers a paid API, or scrape ethically from their sites.
